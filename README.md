# 🏦 SavaliyaOne CLI BANK

SavaliyaOne CLI BANK is a **Python-based Command-Line Banking System** designed to simulate basic banking operations through a terminal interface.

The system allows users to create accounts, securely log in, manage their balance, perform transactions, and view transaction records.

## Features

* Account creation
* User login and authentication
* Account number generation
* Balance checking
* Credit money
* Debit money
* Money transfer
* Transaction history
* Account details
* PIN management
* Transaction analysis
* Data storage and retrieval

## Technologies Used

* Python
* NumPy
* Pandas
* JSON
* File Handling
* Object-Oriented Programming

## Application Flow

```text
Start
  ↓
Main Menu
  ↓
Create Account / Login
  ↓
Authentication
  ↓
Banking Dashboard
  ↓
Credit / Debit / Transfer / Balance
  ↓
Transaction History
  ↓
Analytics
  ↓
Logout / Exit
```

## Data Analysis

NumPy and Pandas are used for analyzing transaction data, including:

* Total credits and debits
* Average transaction amount
* Transaction statistics
* Transaction filtering
* Group-based analysis
* Account transaction records

## Purpose

The project is developed to build a practical understanding of **Python programming, modular programming, file handling, data management, and data analysis** through a real-world banking simulation.

## Disclaimer

SavaliyaOne CLI BANK is an **educational project** and does not connect to real banking systems or process real financial transactions.
